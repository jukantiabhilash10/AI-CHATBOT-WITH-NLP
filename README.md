## 📌 Project Overview
This project is a simple AI chatbot that uses Natural Language Processing (NLP) with the *NLTK (Natural Language Toolkit)* library in Python. The chatbot can handle basic greetings and answer common questions related to NLP, its uses, importance, and examples.

## 🚀 Features
- Responds to greetings and basic NLP-related queries.
- Uses pattern-based matching with predefined responses.
- Implements nltk.chat.util.Chat for conversational flow.
- Provides educational information about NLP.

## 🎯 How It Works
- The chatbot starts with a greeting and instructions.
- The user inputs a message.
- The chatbot matches the input with predefined patterns and responds accordingly.
- The conversation continues until the user types quit.
